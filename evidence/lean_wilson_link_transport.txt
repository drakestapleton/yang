The coupling draws (p,h) from uniform rank times normalized SU(2) Haar.
The link with strength r and pole k is h diag(exp(i Q_r(p)),exp(-i Q_r(p))) h^-1 k^-1.
Haar conjugation reproduces the entire tilted matrix law on each marginal.
The round unit-sphere geodesic equals the angle between the real quaternion
coordinate vectors. At a common pole the lifted coupling's cost equals
its angular cost, giving W2^2 <= (s-r)^2/12. A single pole works at all
bare couplings on a fixed background, yielding W2^2 <= 3 (gamma-beta)^2.
For arbitrary poles the W2 upper bound includes the distance between
centers k^-1 and j^-1. The common-pole degree-18 result assumes both
normalized heat baths admit that pole. A uniform transverse estimate for
changes of background remains open.

import WilsonLinkTransport
open YangMills YangMills.FundamentalSU2 YangMills.PeriodicWilson Real
open scoped ENNReal

-- Degenerate staples: changing the nominal pole at zero strength costs zero.
example (k j : gaugeGroup.image) : linkWassersteinSq (poleLaw 0 k) (poleLaw 0 j) = 0 := by
  have hz (x : gaugeGroup.image) : poleLaw 0 x = su2Haar := by simp [poleLaw]
  rw [hz j,← hz k]
  apply le_antisymm _ zero_le
  simpa using common_pole_wasserstein (r := 0) (s := 0) le_rfl le_rfl k

-- Same-pole changes in strength are controlled in both orders.
example (k : gaugeGroup.image) :
    linkWassersteinSq (poleLaw 0 k) (poleLaw (42/25) k) ≤ ENNReal.ofReal (147/625) := by
  convert common_pole_wasserstein (r := 0) (s := 42/25) (by norm_num) (by norm_num) k using 1
  norm_num
example (k : gaugeGroup.image) :
    linkWassersteinSq (poleLaw (42/25) k) (poleLaw 0 k) ≤ ENNReal.ofReal (147/625) := by
  convert common_pole_wasserstein (r := 42/25) (s := 0) (by norm_num) (by norm_num) k using 1
  norm_num

-- Full periodic heat baths at beta = 0.192 with a common staple pole.
example {l : ℕ+} (hl : 1 < l.val) (U V : Configuration gaugeGroup l) (e : Edge l)
    (k : gaugeGroup.image) (δ : ℝ)
    (hU : heatBath (24/125) U e = poleLaw (fieldStrength (24/125) U e) k)
    (hV : heatBath (24/125) V e = poleLaw (fieldStrength (24/125) V e) k)
    (h : ∀ i ∈ incidences e,
      linkChord (U (neighbor e i.1 i.2).1) (V (neighbor e i.1 i.2).1) / sqrt 2 ≤ δ) :

  norm_num
